## 📌 Mission Overview
This mission evaluates the core capabilities of the three leading public cloud providers (**Amazon Web Services**, **Microsoft Azure**, and **Google Cloud Platform**). It involves analyzing their core primitives, mapping services across providers, delivering architectural recommendations for four client scenarios, and assessing Linux server migration paths.

### 🚀 Cloud Hosting Migration Strategy

If this Linux environment were migrated from KillerCoda to a public cloud vendor, it could be hosted on the following equivalent compute services:

1. **Amazon Web Services (AWS):** Hosted on an **Amazon EC2 `t3.micro` or `t4g.micro` instance** backed by Amazon EBS block storage (`gp3`).
2. **Microsoft Azure:** Hosted on an **Azure Virtual Machine `B1s` or `B2s` size** running Ubuntu LTS.
3. **Google Cloud Platform (GCP):** Hosted on a **Google Compute Engine (GCE) `e2-micro` instance** backed by a GCP Standard Persistent Disk.
