# 💬 Mission 02 Reflection & Critical Evaluation

> **Author:** Christopher Sean O. Gutierrez  
> **Context:** Post-assessment summary for Laboratory 02  

---

Networking is the most important part of cloud systems because it connects everything and makes sure services can talk to each other and reach users. Linux supports cloud computing since most tools and platforms run on it, and it’s simple, open-source, and easy to manage with commands. Writing documentation before setting up cloud systems is needed to avoid mistakes, keep things secure, and control costs. In the lab, I learned useful Linux commands to check system details and saw how they match with cloud services like AWS, Azure, and GCP, while also improving my documentation skills. My GitHub portfolio also got better—it now shows organized notes, logs, and diagrams that make it look more professional and ready for real projects.
