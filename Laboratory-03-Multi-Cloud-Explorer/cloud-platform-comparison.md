## 2. Platform Comparison Analytical Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of cloud services, featuring over 200 fully functional services spanning compute, storage, IoT, quantum computing, and serverless architectures. Being the earliest public cloud entrant, AWS possesses the most mature global ecosystem and expansive market footprint.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best native integration with Microsoft technologies. Organizations using Windows Server, Active Directory, Office 365, or SQL Server benefit from seamless identity sync via Entra ID and cost reductions through Azure Hybrid Benefit licensing options.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is widely recognized as the industry leader in Artificial Intelligence, Machine Learning, and Kubernetes container management. Since Google originally created Kubernetes and open-sourced it, GCP offers the most optimized managed Kubernetes service (GKE) along with advanced AI tools like Vertex AI and TPUs.

### 4. Which cloud platform would you personally choose and why?
I would personally choose **Google Cloud Platform (GCP)** due to its technical excellence in containerization and modern developer workflows. GCP's native integration with Google Kubernetes Engine (GKE) and its high-speed global private fiber network make it ideal for deploying cloud-native applications efficiently.
