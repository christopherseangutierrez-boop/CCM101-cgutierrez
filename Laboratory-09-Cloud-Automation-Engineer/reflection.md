Automation is critical when managing hundreds of cloud servers because manual administrative operations do not scale, introducing severe bottlenecks and human
errors that compromise reliability. 

However, automation carries inherent risks; if a script containing a destructive bug or syntax error is scheduled to execute automatically across 1,000 servers
simultaneously, it can propagate catastrophic failures at machine speed before an operator can intervene. 

Writing a Bash script differs from creating a Docker Compose YAML file because a Bash script is an imperative sequence of procedural shell commands executed
sequentially, whereas a Docker Compose file is a declarative infrastructure blueprint that defines desired multi-container states. 

Reviewing my entire GitHub repository from Laboratory 1 through Laboratory 9, my understanding of cloud computing has transformed dramatically. Starting from
basic cloud conceptualization and virtual machine deployment, progressing through cloud data engineering, container orchestration, SRE monitoring, and security
hardening, and culminating in automation, I have built a robust foundation in modern cloud engineering. 

Among all the roles explored this semester, I enjoyed the **Cloud Automation & DevOps Engineer** role the most. Building self-sustaining routines, eliminating
tedious manual tasks through shell scripting, and mastering autonomous cron scheduling demonstrated the true power of scalable cloud operations.
