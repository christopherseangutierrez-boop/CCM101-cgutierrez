# Mission Reflection

### 1. Which cloud infrastructure component do you think is the most important? Why?
In my opinion, networking is the most critical cloud infrastructure component. While compute and storage power application logic and data, networking provides the foundation that connects users to resources, routes internal microservices, and enforces boundary security. Without robust virtual private networks and firewalls, compute instances and storage buckets cannot interact safely or serve end users effectively.

### 2. How does Linux support cloud computing?
Linux serves as the backbone of modern cloud computing infrastructure. The vast majority of cloud instances, container host nodes, and hypervisors run on Linux kernels due to its open-source flexibility, security model, performance efficiency, and powerful command-line scripting capabilities. Linux native primitives like namespaces and cgroups also form the underlying engine for containerization platforms like Docker and Kubernetes.

### 3. Why is technical documentation important before deploying infrastructure?
Technical documentation ensures architectural clarity, security alignment, and cost efficiency prior to provisioning costly cloud resources. Designing infrastructure blueprints beforehand prevents deployment bottlenecks, allows senior engineers to review compliance standards, and provides a clear operational manual for maintenance and troubleshooting.
