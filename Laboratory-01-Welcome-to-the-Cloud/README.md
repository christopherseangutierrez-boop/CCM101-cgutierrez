# Mission 01: Welcome to the Cloud

## Mission Overview
Completed onboarding activities as a Junior Cloud Infrastructure Engineer Trainee, setting up a Linux environment and establishing a GitHub cloud portfolio.

## Objectives
- Access cloud-based Linux environment via KillerCoda.
- Gather system specifications and organize directories.
- Set up version control and document work using Markdown.

## Activities Performed
- Checkpoint 1: User creation and account setup.
- Checkpoint 2: Gathering Linux distribution, kernel, CPU, RAM, and disk specs.
- Checkpoint 3: Building local folder structures and user profiles.
- Checkpoint 4 & 5: Structuring GitHub portfolio and mission documentation.

## Linux Commands Used
- `useradd`, `passwd`, `usermod`, `su`
- `whoami`, `pwd`, `hostname`, `uname`, `lscpu`, `free`, `df`
- `mkdir`, `nano`, `cat`, `ls`, `git`

## Skills Learned
- Basic Linux administration and navigation.
- Technical documentation writing using Markdown.
- Portfolio management using Git and GitHub.
