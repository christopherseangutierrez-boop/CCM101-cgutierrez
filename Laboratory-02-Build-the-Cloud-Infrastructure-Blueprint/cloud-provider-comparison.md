# Cloud Provider Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | Google Virtual Private Cloud (VPC) |
| **Identity & Access Management (IAM)** | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Google Cloud IAM |

---

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest and most comprehensive range of services among the major cloud platforms. As the pioneer in public cloud computing, AWS features the most mature global infrastructure, an extensive service catalog, and a massive ecosystem of third-party integrations.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is the best recommendation for an organization deeply integrated with Microsoft products. Azure provides seamless native integration with Active Directory, Windows Server, Office 365, and enterprise licensing discounts (such as Azure Hybrid Benefit) that significantly lower overall migration costs.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized as an industry leader in AI, ML, and Kubernetes management. Google originally created Kubernetes and built GCP around high-performance big data analytics, Tensor Processing Units (TPUs), and advanced machine learning frameworks like TensorFlow.

### 4. What similarities did you observe among the three cloud providers?
All three cloud providers offer equivalent foundational infrastructure primitives including virtualized compute instances, scalable object storage, private virtual networks, and granular access control (IAM). Furthermore, each platform implements a pay-as-you-go pricing model, multi-region redundancy, and rigorous security management standards.
