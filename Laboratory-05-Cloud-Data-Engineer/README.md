## 📌 Mission Overview
This mission explores cloud data storage architectures, differentiating between block, file, and object storage. Acting as a Cloud Data Engineer at CloudNova Technologies, this laboratory covers deploying a high-performance, S3-compatible object storage server (MinIO) via Docker, configuring environment credentials, managing storage buckets, and handling unstructured data uploads.

---

## 🎯 Objectives
* Differentiate between Block, File, and Object storage types.
* Deploy a containerized S3-compatible storage cluster using MinIO.
* Utilize Docker environment variables (`-e`) for secure credential management.
* Port-forward containerized management interfaces to a web browser.
* Create storage buckets and upload media objects.

---

## 🧰 Tools Used
* **KillerCoda Ubuntu Playground**
* **Docker & Docker CLI**
* **MinIO Server**
* **GitHub Version Control**

---

## 💡 Skills Learned
* Architecting cloud solutions using object storage instead of traditional block volumes for unstructured files.
* Passing environment-level security parameters during container initialization.
* Interacting with S3-compatible web consoles for bucket administration and file management.
